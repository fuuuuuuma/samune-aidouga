# YouTubeの作風を覚えるサムネイル制作

参考にしたいYouTubeのURLを一度渡すと、サムネイルの配色・文字・構図を分析して保存するCodexプラグインです。次回からは「前に覚えた作風で作って」で制作できます。特定のチャンネルの学習データは同梱していません。

## 視聴者向け：この2行でインストール

Codex CLIが使えるターミナルに、次の2行を貼り付けてください。

```bash
codex plugin marketplace add fuuuuuuma/samune-aidouga
codex plugin add samune-aidouga@samune-aidouga
```

導入後は新しいCodexチャットを開き、プラグインまたは `$samune-aidouga` を指定して依頼します。

## 最初の1回

```text
$samune-aidouga このYouTubeチャンネルのサムネイルの作風を学習して覚えてください。
https://www.youtube.com/@参考にしたいチャンネル
```

チャンネルのURLのほか、動画のURL・`youtu.be` の共有リンク・ShortsやライブのURLでも投稿元を特定できます。動画URLから登録する場合は、その動画のサムネも資料へ含めます。

通常は通常動画の公開一覧上位30件を集め、Codexが実際に画像を確認します。Shortsは別の作風として分析します。「全動画・Shorts・ライブを学習して」と指定すれば取得範囲を広げられます。動画本体と音声は取得しません。

## 2回目から

```text
$samune-aidouga 前に覚えた作風で、添付のラフと人物写真からサムネを作って。
```

URLを再送する必要はありません。新しいチャットでも最後に学習・選択した作風を読み戻します。初回は完成画像3案、修正は2案が標準です。「今回は1案だけ」などの指定もできます。ラフがなければ動画のテーマ・入れたい文字を伝え、構図を任せられます。

複数登録した場合は「登録した作風を一覧にして」「○○チャンネルの作風へ切り替えて」、新しい投稿も反映したい場合は「このチャンネルの学習を更新して」と依頼してください。採用例や継続する修正指示も、そのチャンネルの記録へ保存します。

## 記憶の保存先

標準は **`~/.samune-aidouga/`** です。登録一覧と現在の作風、参考画像、観察結果、制作ルール、修正履歴をプラグインの外に保存するので、プラグインの更新・再インストール後も引き継げます。

学習とは、保存した資料とルールを毎回読み戻す仕組みです。モデルを追加訓練する機能ではありません。同じPC・同じユーザーでの継続利用が対象です。PCの移行時はこのフォルダをコピーしてください。

保存先を変える場合は、毎回同じ `SAMUNE_AIDOUGA_DATA_ROOT` 環境変数を設定してください。以前の版で任意の `DATA_ROOT` に保存していた資料は、新しい標準保存先に自動移動しません。Codexにその保存場所を伝え、プロファイルと観察CSVを確認した上で登録するか、URLから登録し直せます。

## 必要な環境

- プラグイン機能が使えるCodex CLI／Codexアプリ。ターミナルで `codex` が使えること。
- Python 3.10以降と、Pythonの仮想環境・pipが使えること。
- 初回の参考取得にはネット接続。Python依存は同梱の `requirements.txt` をCodexが専用環境へ導入します。
- 完成画像の制作にはCodex内の画像生成・編集ツールが必要です。画像生成の利用可否・利用枠は利用環境に従います。ツールがない環境でも登録・分析はできます。

2行はプラグインの導入コマンドです。CodexやPython自体のインストールは含みません。

## すでに導入済みの方

```bash
codex plugin marketplace upgrade samune-aidouga
codex plugin add samune-aidouga@samune-aidouga
```

更新後に新しいチャットで依頼してください。初回導入・更新とも、学習済みデータを消す必要はありません。

## データの扱い

参考チャンネルから学ぶのは構図・配色・文字の扱いです。第三者の顔・ロゴ・コピー・成果数値を利用者の動画へ自動転用しません。登録した画像や人物写真、APIキーはこのリポジトリへ保存しません。YouTube・Xへの投稿は利用者が行います。

収集は [yt-dlpのPythonインターフェース](https://github.com/yt-dlp/yt-dlp#embedding-yt-dlp) を使い、公開メタデータと現在のサムネを対象にします。削除・非公開・アクセス制限のある投稿や、過去のサムネ全履歴は網羅しません。取得や画像生成の失敗を学習完了・制作完了として報告しない手順を含みます。
