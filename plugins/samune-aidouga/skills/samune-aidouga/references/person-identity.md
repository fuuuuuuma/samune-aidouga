# 人物本人性

第一参照はユーザー提供の本人素材。別チャンネルの人物やスタイル参考の顔を本人参照へ混ぜない。顔の特徴から名前・属性を推測しない。

元写真の顔・表情・姿勢を維持する構成を標準とする。利用環境で許可されるなら元人物を合成し、顔を生成し直さない。生成編集を使う場合は本人写真を明示し、変更対象と保護対象を分ける。

画像全体がFHDでも、顔部分の実画素数や元の描写情報が十分とは限らない。鮮明化と本人性の保持を別々に検査する。元画像に無い歯・目・肌の細部を推測で足して「復元」と呼ばない。

画像生成・編集では本人性を最優先し、手は顔と別に指・関節・重なりを点検する。ツールに局所編集やマスク機能がある場合は、元顔参照を保ちながら対象範囲を限定する。

ポーズ・服装・表情の変更はユーザー意図に含まれ、元写真では成立しない時だけ。美肌化・小顔化・若返り・目の拡大・左右対称化等を勝手に加えない。輪郭、目、鼻、口、歯、顎、肌色、髪、生来の特徴、眼鏡などを比較する。

ローカルの比較シートを作れる環境では補助スクリプトを使える。これは本人判定を自動化するものではない。

```bash
python3 SKILL_ROOT/scripts/make_person_identity_qc.py \
  --reference person_source.png --candidate final.jpg \
  --reference-face-box x1,y1,x2,y2 --candidate-face-box x1,y1,x2,y2 \
  --output person_identity_qc.png
```

原寸の顔拡大と縮小画像を目視して照合する。「似ている」だけで合格にしない。1回目の失敗は元参照へ戻して変更範囲を絞る。2回目も別人化する場合は、元写真を保つ構図へ戻すか別の実写真を求める。失敗画像を次回の本人参照にしない。

仕上げ時にも顔を保護し、元写真との照合を繰り返す。人物素材はユーザーが指定した案件範囲で使い、スキル共有ZIPや別チャンネルの共有アセットへ自動追加しない。


## 専用写真を生成前に確認
人物入りサムネは支給フォルダ・案件素材・当該チャンネルの人物素材台帳を確認し、専用の元写真があるかを記録する。既存サムネの切り抜きより専用写真を優先する。ユーザーが今回の人物を了承している場合はその承認を記録し、聞き直さない。外部チャンネルの人物は借用しない。
